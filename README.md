# 🍱 ОбедКласс — заказ еды для школьной столовой

Приложение для онлайн-заказов еды в школьных столовых. В каждом классе есть **староста-админ**:
он отмечает учеников, которые будут завтракать и обедать, и одной кнопкой отправляет заказ в столовую.

> Сейчас в репозитории — **визуальный дизайн** (кликабельный макет с демо-данными, без бэкенда).
> Классы школы: **5–11 параллели, буквы А–Д** — всего 35 классов.

## Как это работает

1. **Вход** — при открытии сайта выбор роли: **«Я староста»** или **«Я из столовой»**.
2. **Староста** — выбирает свой класс и придумывает пароль (в макете пароль никуда не сохраняется).
   Дальше: отметки «Завтрак» / «Обед» у каждого ученика, быстрые кнопки
   «Всем завтрак» / «Всем обед», итоговые счётчики и большая кнопка
   **«Отправить в столовую»** (после отправки заказ можно отредактировать и отправить повторно).
3. **Столовая** — живая сводка по всей школе: сколько классов отправило заказ,
   сколько всего завтраков и обедов готовить, статусы по каждому классу с фильтрами
   «Все / Отправлено / Ожидают».

## Стек

- **Next.js 16** (App Router) + **TypeScript**
- **Tailwind CSS 4** + **shadcn/ui**, иконки Lucide
- Шрифт **Nunito** (кириллица), тёмная/светлая темы на `next-themes`
- Демо-данные: детерминированная генерация классов и учеников (`src/lib/school-data.ts`)

## Запуск локально

```bash
bun install   # или npm install
bun run dev   # или npm run dev
```

Открыть http://localhost:3000

## Структура

```
src/
├── app/                  # страница-макет (единственный route)
├── components/canteen/   # welcome, вход старосты, шапка, список учеников, экран столовой
├── components/ui/        # shadcn/ui
└── lib/school-data.ts    # типы + мок-данные школы (35 классов, 5–11)
```
