# 🍱 ОбедКласс — заказ еды для школьной столовой

Приложение для онлайн-заказов еды в школьных столовых. В каждом классе есть **староста-админ**:
он отмечает учеников, которые будут завтракать и обедать, и одной кнопкой отправляет заказ в столовую.

> Сейчас в репозитории — **визуальный дизайн** (кликабельный макет с демо-данными, без бэкенда).

## Как это работает

- **Роль «Староста»** — выбор своего класса из сетки **55 классов** (11 параллелей × буквы А–Д),
  отметки «Завтрак» / «Обед» у каждого ученика, быстрые кнопки «Всем завтрак» / «Всем обед»,
  итоговые счётчики и большая кнопка **«Отправить в столовую»** (после отправки заказ можно отредактировать).
- **Роль «Столовая»** — живая сводка по всей школе: сколько классов отправило заказ,
  сколько всего завтраков и обедов готовить, статусы по каждому классу с фильтрами «Все / Отправлено / Ожидают».

## Стек

- **Next.js 16** (App Router) + **TypeScript**
- **Tailwind CSS 4** + **shadcn/ui**, иконки Lucide
- Шрифт **Nunito** (кириллица), тёмная/светлая темы на `next-themes`
- Демо-данные: детерминированная генерация классов и учеников (`src/lib/school-data.ts`)

## Запуск локально

```bash
bun install   # или npm install
bun run dev   # или npm run dev
```

Открыть http://localhost:3000

## Структура

```
src/
├── app/                  # страница-макет (единственный route)
├── components/canteen/   # шапка, сетка классов, список учеников, экран столовой
├── components/ui/        # shadcn/ui
└── lib/school-data.ts    # типы + мок-данные школы (55 классов)
```
