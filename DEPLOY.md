# Выкладываем ОбедКласс в интернет 24/7

Проект можно развернуть бесплатно на **Vercel** (хостинг) + **Neon** (облачная база данных).
Сайт получит постоянную ссылку вида `https://school-canteen-….vercel.app`, будет работать
круглосуточно, а каждое обновление кода на GitHub будет автоматически обновлять сайт.

Всё нужное для деплоя уже лежит в репозитории: `vercel.json` (сборка),
`prisma/schema.deploy.prisma` (схема для PostgreSQL). Ничего в коде менять не нужно.

Понадобится: аккаунт GitHub (он уже есть) и минут 10 времени. Банковская карта не нужна.

---

## Шаг 1. Регистрация на Vercel

1. Открой [vercel.com](https://vercel.com) и нажми **Sign Up**.
2. Выбери **Continue with GitHub** и разреши Vercel доступ к аккаунту.
3. На вопрос про команду выбери личный аккаунт (Hobby — бесплатный план).

## Шаг 2. Импорт проекта

1. На главной панели нажми **Add New… → Project**.
2. В списке репозиториев найди **school-canteen** и нажми **Import**.
3. Vercel сам определит Next.js. Ничего не меняй и нажми **Deploy**.

Первый деплой упадёт (красный экран) — **это нормально**: проекту ещё не к чему
подключить базу данных. Ошибка будет звучать как `Environment variable not found:
DATABASE_URL`. Идём дальше.

## Шаг 3. База данных Neon (внутри Vercel)

1. Открой вкладку **Storage** вверху панели проекта.
2. Нажми **Create Database** → выбери **Neon** из маркетплейса → **Continue**.
3. План — **Hobby (Free)**. Имя базы: `obedclass-db`. Регион: **Frankfurt
   (Europe)** — ближе всего к России. Нажми **Create**.
4. Vercel сам создаст базу и добавит переменные `DATABASE_URL` и `DIRECT_URL` —
   их вводить вручную не нужно.
5. Добавь ещё одну переменную вручную: **Settings → Environment Variables**:
   - Key: `SESSION_SECRET`
   - Value: любая длинная случайная строка, минимум 40 символов
     (например `kot-bor9-2mXq7Ld4pR8sT3vW6yZ1aQ5nC0jF4hG` — но лучше придумай свою)
   - Environments: отметь все три (Production, Preview, Development)
6. Открой вкладку **Deployments**, у самого верхнего деплоя нажми меню **⋯ →
   Redeploy** (галочку «Use existing Build Cache» можно снять).

Через пару минут сборка позеленеет — при сборке Vercel сам создаёт таблицы в базе
(`prisma db push` прописан в `vercel.json`).

## Шаг 4. Проверка

Открой ссылку проекта (кнопка **Visit** на панели проекта) и пройди весь путь:

1. **«Я староста»** → выбери свой класс → придумай код из 6 цифр → запиши его!
2. Отметь пару учеников на завтрак и обед → **«Отправить в столовую»**.
3. Открой сайт с телефона (или в другом окне) → **«Я из столовой»** →
   в списке виден твой класс со штампом времени и количеством порций.
4. Перезагрузи страницу старосты — вход и отметки должны сохраниться.

Готово — сайт работает 24/7, ссылку можно давать одноклассникам и учителям.

---

## Как обновлять сайт

Изменил код → `git push` → Vercel сам пересоберёт и обновит сайт за 1–2 минуты.
Ничего нажимать не нужно.

## Если что-то не получилось

| Симптом | Что делать |
| --- | --- |
| Сборка красная, `Environment variable not found: DATABASE_URL` | База Neon не подключена — шаг 3, пункты 1–4 |
| Сборка красная, `Environment variable not found: DIRECT_URL` | Та же причина: переменную ставит интеграция Neon. Проверь вкладку Storage, что база существует и привязана к проекту |
| Сайт открывается, но вход сбрасывается после перезагрузки | Не задан `SESSION_SECRET` — шаг 3, пункт 5, затем Redeploy |
| Забыл код класса | Зайди на Vercel → Storage → Neon → Open Neon Console → SQL Editor → выполни `DELETE FROM "ClassAuth" WHERE "classId" = '6В';` (подставь свой класс). После этого класс сможет придумать код заново |
| Vercel не открывается или не пускает регистрацию | Иногда доступ из России нестабилен. Попробуй VPN или альтернативы ниже |

## Альтернативы Vercel

Если с Vercel не сложилось, тот же репозиторий можно развернуть на:

- **Amvera** ([amvera.ru](https://amvera.ru)) — российский хостинг, есть бесплатный
  тариф, деплой прямо из GitHub, PostgreSQL в комплекте. Интерфейс на русском.
- **Railway** ([railway.app](https://railway.app)) — красиво и просто, но бесплатный
  пробный лимит быстро кончается.
- **Render** ([render.com](https://render.com)) — бесплатный тариф засыпает без
  трафика и не хранит данные, подойдёт только для демонстрации.

На всех платформах понадобятся те же три переменные: `DATABASE_URL`,
`DIRECT_URL` и `SESSION_SECRET`, а команду сборки можно взять из `vercel.json`.

## Почему именно так

Локально проект хранит данные в SQLite (файл `db/custom.db`), но на хостинге файловая
система пересоздаётся при каждом деплое — там нужна настоящая база. Поэтому в репозитории
две схемы Prisma: `prisma/schema.prisma` (SQLite, для разработки) и
`prisma/schema.deploy.prisma` (PostgreSQL, для Vercel). Vercel при сборке использует
вторую схему: создаёт таблицы и генерирует клиент. Коды классов хранятся в базе
в виде bcrypt-хэшей, сессии — в подписанных httpOnly-cookie.
